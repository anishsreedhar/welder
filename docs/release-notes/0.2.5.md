Welder 0.2.5: one Windows download with an update check, smoother 4K playback, no idle churn on big
EXRs, ML on offline machines, and the Mac builds are back.

## New

- **One Windows download.** `welder-0.2.5-win64.zip` now includes the .nk importer's Python and the
  RIFE models. There are no separate `-python` or `-rife-models` zips any more. The Linux tarball
  includes the RIFE models too. (#85, #93)
- **Update available.** Welder checks GitHub for a newer release at most every 12 hours. When there
  is one, "Update available" appears in the menu bar with the release notes. **Help › Check for
  Updates** checks right away, and **Preferences › Updates** turns it off. Nothing is downloaded or
  installed, and nothing about you is sent. (#85, #93)
- **ML on offline machines.** Set up ML on a machine with internet, then copy the ML folder to an
  offline one and Welder repairs it on startup. A new **offline** checkbox stops all downloads.
  `WELDER_ML_VRAM_GB` caps GPU memory, so you can try 12 GB settings on a bigger card. See
  docs/ML.md. (#81, #94)
- **Roto points.** Points show on the current shape and the shape under the mouse before you select
  them. The ends of thin open splines are easier to pick. **Always show points** is now remembered,
  and it's in Preferences under Roto. This applies to Roto, RotoPaint and Power Roto. (#97)
- **Node graph zooms out further**, so a 200+ node imported script fits. **F** frames everything.
  (#83, #92)

## Faster

- **4K playback.** Cached frames go to the GPU as half floats, so playback at full size holds 24 fps
  more often. (#96, #98)
- **Full res off.** Frames cached at full res are reused straight away when Full res is turned off,
  instead of re-rendering for a loop. (#101)
- **Big EXRs at idle.** An idle Welder no longer keeps decoding large EXR sequences, which caused
  constant CPU and network use on shares. Connecting nodes is quicker too. (#83, #92)

## Fixed

- Playback could stop for good after a knob edit. (#101)
- The Mac builds compile again (0.2.4 had none). (#95)

## Downloads

- **Windows:** `welder-0.2.5-win64.zip`
- **Linux:** `welder-0.2.5-linux-x86_64.tar.gz`
- **macOS, Apple silicon:** `welder-0.2.5-macos-arm64.zip`
- **macOS, Intel:** `welder-0.2.5-macos-x86_64.zip`

The Mac app isn't signed yet, and it has no GPU support. The first time you open it, right-click
Welder.app and choose **Open**.
