Welder 0.2.2: a fix for roto tools that stopped responding.

## Fixed

- **Roto tools stopped responding with more than one Roto, RotoPaint or Power Roto open.** Each open
  roto panel reset the viewer's roto tools. (#65)

## Downloads

- **Windows:** `welder-0.2.2-win64.zip` (plus `-python.zip` and `-rife-models.zip`)
- **Linux:** `welder-0.2.2-linux-x86_64.tar.gz` (plus `-rife-models.tar.gz`)
- **macOS, Apple silicon:** `welder-0.2.2-macos-arm64.zip`
- **macOS, Intel:** `welder-0.2.2-macos-x86_64.zip`

The Mac app isn't signed yet, and it has no GPU support. The first time you open it, right-click
Welder.app and choose **Open**.
