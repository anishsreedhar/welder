Welder 0.2.0: Power Roto, 3D scene cards, a CorridorKey keyer, a Markup node for review notes, film-look nodes,
steadier viewer tools, and fixes for ImageGen on 24 GB cards and for large model downloads.

## New

- **Power Roto.** A new roto node alongside Roto, with X-spline shapes, freehand and magnetic
  freehand drawing that snaps to image edges, magnetic and brush reshape, snap to edges, point
  groups and shape operations (split, join, extract, tween, distribute), and per-shape grow/shrink,
  inner/outer edge blur, output channel and add/subtract/difference blends. (#56)
- **3D scene cards: Scene3D and CardTransform.** Import a tracked camera and point cloud (FBX
  natively, Alembic through Blender), fit a plane to selected points and drag out named cards in the
  3D viewer (world/local gizmos, quad view), then pin images to a card with CardTransform's Insert,
  Match Move and Stabilize modes. (#57)
- **Film looks.** FilmBurn and FilmBurnTransition, LightLeak and LightLeakDissolve, Dust (specks,
  hairs, scratches, gate weave) and MultiTone (four switchable tones for shadows, mids, highlights
  and an extra). (#55)
- **Markup.** Paint strokes, boxes, circles and text over the picture for review notes. Every item
  stays editable in the viewer or the panel's item list, and **Save image** writes the current frame
  as PNG, JPEG, TIFF or EXR at full, half or quarter resolution. (#53)
- **Write names its file after the comp.** A new Write starts with `<comp name>.####.exr` beside
  the comp. (#51)

## New: AI

- **CorridorKey.** Corridor Digital's CorridorKey 2.0 keys a green or blue screen plate over the
  whole clip, with an optional hint matte, and shows the despilled foreground with its matte. Its
  licence (CC BY-NC-SA 4.0 with extra terms) doesn't allow bundling it with Welder, so the node's
  **Download** fetches it from Corridor Digital's GitHub and Hugging Face (about 5 GB) into an
  environment of its own. (#52)
- **ImageGen on 24 GB cards.** FLUX.2 [klein] base no longer fails with "Expected all tensors to be
  on the same device" with model offload (#47), and a batch keeps the model on the GPU instead of
  reloading it for every take (#50).

## Fixed

- **Viewer clicks that did nothing and handles that didn't show.** The viewer's tools now follow
  the panel you're working in, a colour pick left on in another panel no longer takes the viewer's
  clicks, and floating panels show their handles. (#49)
- **Large model downloads breaking off** with "File reconstruction error: Internal Writer Error:
  Background writer channel closed" (seen with LTX-2.5 22B on Windows). Welder retries over plain
  HTTP, keeping the files already done, and says to check disk space if that fails too. (#54)
- **.nk import:** a failed import now says so in a dialog instead of only in the status line. (#27)
- Fixes for IBKColour (#45) and for Merge when the A input has no alpha (#30). (#48)
