Welder 0.1.8: FLUX 3 [klein] in ImageGen, ComfyUI split model files, and fixes for the Keyer's alpha
and for viewer overlays that stayed on screen after their panel was folded.

## New: AI

These run on Welder's ML worker (**Set up ML** in the node's properties) and need an NVIDIA GPU.
The models download from Hugging Face the first time, each under its own licence (see `docs/ML.md`).

- **ImageGen: FLUX 3 [klein].** FLUX 3 [klein] and [klein] base run alongside FLUX.2 in the same
  node. Img2Img, Inpaint, up to 10 reference images (named `<ref_image_0>`, `<ref_image_1>` and so
  on in the prompt), LoRAs and the samplers all work. BFL single files load too, including the fp8r
  and nvfp4 versions and ComfyUI's fp8 files. An optional prompt upsampler is under Advanced (off by
  default). FLUX 3 is free for companies under $5M annual revenue; see `docs/ML.md`. (#41)
- **ImageGen: ComfyUI split files.** A FLUX.2 [klein] transformer `.safetensors` now runs with
  separate Qwen3 text encoder and FLUX.2 VAE files, found next to it in the checkpoints folder or in
  ComfyUI's `text_encoders/` and `vae/` folders. The Model card has pickers for the text encoder and
  the VAE, and only the small Qwen3 tokenizer is downloaded. FLUX.2 [dev]'s Mistral text encoder
  files aren't supported this way yet. (#42)

## Fixed

- **Keyer: the alpha was solid white.** The default range is now 0 1 1 1. (#31)
- **Roto, Tracker and Transform overlays stayed in the viewer** after their properties panel was
  folded. A folded panel now hides its overlays. (#29)
