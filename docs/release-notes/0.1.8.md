Welder 0.1.8: FLUX 3 [klein] in ImageGen, next to FLUX.2.

## New: AI

- **ImageGen: FLUX 3 [klein].** ImageGen now also runs Black Forest Labs' FLUX 3 Image [klein]
  (4 to 16 steps) and [klein] base (about 50 steps, with guidance and a negative prompt), alongside
  FLUX.2 [dev] and [klein], which work as before. Everything the node does works with it: Img2Img,
  Inpaint, up to 10 reference images (name them in the prompt as `<ref_image_0>`, ...), LoRAs,
  samplers and previews. BFL's single files, their fp8r / nvfp4 versions and ComfyUI fp8 files load
  too. An optional **prompt upsampler** (Advanced, off by default) rewrites the prompt with BFL's
  upsampler first. Put the Hugging Face folder in the checkpoints folder; FLUX 3 is free for
  companies under $5M annual revenue (see `docs/ML.md`).
