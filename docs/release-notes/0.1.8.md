Welder 0.1.8: the Keyer's alpha, and viewer overlays of folded panels.

## Fixed

- **Keyer: a solid white alpha.** A new Keyer's range was 0 0 1 1, which keyed every value to full
  alpha. It's 0 1 1 1 now, as in Nuke: the key follows the measured value. (#31)
- **Viewer overlays of a folded panel.** Folding a node's panel in the properties bin now hides its
  Roto splines, Tracker points or Transform handles in the viewer, as closing it does. (#29)
