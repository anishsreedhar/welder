Welder 0.1.9: fixes for the ML worker after an update, and for Comfy-Org's FLUX.2 VAE file.

## Fixed

- **"unknown task 'imagegen'" after updating Welder.** An ML worker left running from an older
  version is now restarted. (#43)
- **"No module named 'diffusers'".** When the installed ML packages are older than this Welder needs,
  the ML worker row in Preferences shows an **Update ML** button. (#43)
- **ImageGen: Comfy-Org's `flux2-vae.safetensors`** (with Diffusers-style names) now loads. (#43)
