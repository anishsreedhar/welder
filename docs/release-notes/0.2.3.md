Welder 0.2.3: Psychic Rendering and optical flow on the GPU.

## Faster

- **Psychic Rendering on the GPU.** FlowBreath, FractalFold, SpectralPhase and TemporalTracer now
  render on the GPU when one is available, and fall back to the CPU when there is none or it's
  switched off in Preferences. (#70)
- **Optical flow on the GPU.** The flow solver runs on the GPU too, which speeds up everything that
  uses it: VectorGenerator (and so FlowBreath and TemporalTracer with vectors connected), the
  retimers, the restore nodes and Roto tracking. (#70)

## Also

- The repository now checks every push for committed keys, tokens and local settings files. (#69)
